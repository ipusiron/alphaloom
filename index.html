列ごとの候補文字を組み合わせ、辞書の語と照らして鍵の候補を探す

暗号文から列の候補を作る（ヴィジュネル暗号・使わなくてもよい）

暗号文と鍵の長さを入れると、列ごとに鍵の文字を英語らしさの順に並べて上位を下の列に入れ、 辞書の語を「その語で戻した文の英語らしさ」の順に並べます。鍵が英単語なら、列ごとの1位がそろわない短い暗号文でも鍵が上位に出ます。

英字だけを使います（空白・記号・数字は無視、10,000字まで）

1) 入力

英字はその位置の文字、「?」はどの文字でもよい列です（文字数も合わせて変わります）

各列に、その位置に来そうな文字を優先順に入れます（例: CAB は C＞A＞B の順に重い。重みは 3:2:1）。 空欄の列はA〜Zの26文字を同じ重みで扱います。全角英字も使え、同じ文字は1つにまとめます。

重みの大きい順に、この件数を正確に求めます（打ち切りや近似はしません）

暗号文での照合（辞書の語を英語らしさの順に）

# 鍵（辞書の語） 英語らしさ 戻した文（先頭）

列ごとの鍵の文字（英語らしさの順）

列 1位 2位 3位 4位 5位

この暗号文をほかのツールで開く

    2) 組み合わせ（重みの大きい順）

    # 鍵の候補 重み 辞書の語 戻した文（先頭）

    3) 辞書の語との照合

    使っている辞書の語のうち、同じ文字数で、どの位置の文字も列の候補に入っている語を、重みの大きい順に並べます。 保持した件数に入らない語も漏らしません。

    # 辞書の語 重み 戻した文（先頭）

    辞書設定

    照合に使う辞書を選びます。複数を同時に使え、同じ語は1つにまとめます。辞書の語は英字だけに直して使います。

    辞書の一覧

      いま使っている辞書

      合計の語数: 0

      自分の辞書を追加

      読み込んだ辞書はこのページの中だけで使い、どこにも送りません。ページを閉じると消えます。

      使い方

      1. 文字数（1〜20）を選ぶと、列1〜列Nの欄が並びます。パターン（例: ?HE??）から埋めることもできます。
      2. 各列に、その位置に来そうな文字を優先順に入れます。並べた順に重みが強くなり、空欄の列はA〜Zの26文字を同じ重みで扱います。
      3. 「組み合わせを作る」で、重みの大きい組み合わせから順に、保持する件数だけ並べます。重みは各列の重みの積で、すべての組み合わせの合計が100%です（正解である確率ではありません）。
      4. 「辞書の語との照合」に、列の候補に合う辞書の語が重みの順に並びます。鍵が英単語のときは、まずこちらを見ます。
      5. 「辞書設定」で、照合に使う辞書を選んだり、自分の語の一覧を足したりできます。

      ヴィジュネル暗号の鍵を探すとき

      鍵の長さが分かったら、暗号文を鍵の長さで列に分け、列ごとに「英文らしく戻るずらし（鍵の文字）」の上位を各列に入れます。 鍵が英単語なら、「辞書の語との照合」の上位に鍵が出ることが多くなります。
