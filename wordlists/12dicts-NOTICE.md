## Contents / 内容

The ReadMe describes 3of6game as a list of words "listed in 3 of the 6 advanced learners dictionaries", designed for word games: it excludes hyphenated words, multi-word phrases, capitalized words, abbreviations and contractions, and includes inflections (plurals, verb forms). Some words carry one-character annotation suffixes (`^`, `&`, `$`, `+`, `!`) that mark exceptions such as variant spellings and neologisms. Anagram Hunter keeps only the letters A-Z of each line, so the suffixes are dropped and all 64,662 lines are used as words.

ReadMe によると、3of6game は学習者向けの上級辞書6冊のうち3冊に載る語のリストで、ワードゲーム向けに作られています（ハイフンつきの語・句・大文字で始まる語・略語・短縮形を除き、複数形や動詞の活用形を含む）。一部の語の末尾には注記の記号（`^`・`&`・`$`・`+`・`!`）が付いています。Anagram Hunter は各行の英字だけを使うので、記号は外れ、64,662行すべてが語になります。
